# CyberGuardian - Network Scanner 🛡️

مجموعة من أدوات وموارد الأمن السيبراني للاستخدام التعليمي والاختبارات الأمنية المصرح بها.

## 📋 حول الأداة

**ماسح الشبكة (Network Scanner)** — أداة قوية لفحص الشبكات والأجهزة واكتشاف المنافذ المفتوحة والخدمات.

### المميزات الرئيسية:
- 🔍 فحص الأجهزة المتصلة بالشبكة
- 🔎 اكتشاف المنافذ المفتوحة
- 📊 تحديد الخدمات والبروتوكولات
- 🎯 مسح سريع وفعال
- 📱 يعمل على Termux و Linux

## 🚀 البدء السريع

### المتطلبات:
- Linux أو Termux
- bash 4.0+
- nmap أو netstat
- python3 (اختياري)

### التثبيت:
```bash
git clone https://github.com/770688917bb-debug/CyberGuardian.git
cd CyberGuardian
chmod +x network_scanner.sh
```

### الاستخدام:
```bash
./network_scanner.sh [IP_RANGE]
```

مثال:
```bash
./network_scanner.sh 192.168.1.0/24
```
